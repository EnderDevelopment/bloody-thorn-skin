# Minecraft Texture Pack – Bloody Thorn Skin

Bloody Thorn Skin is a custom Minecraft character skin texture featuring a cream-colored spiky hairstyle, a dark crimson thorn-inspired crown, a silver necklace, a white tank top with crimson thorn graphics, and dark maroon pants. Designed with a blocky Minecraft aesthetic, this texture provides a distinctive gothic-inspired appearance with a white, black, and blood-red color theme.

## Install

1. Download the project files from the GitHub repository.
2. Locate `assets/skins/ender_skin.svg`.
3. Open the SVG file in a compatible vector graphics editor.
4. Export or convert the texture into a Minecraft-compatible PNG skin format.
5. Upload the converted PNG through the Minecraft Skin settings.
6. Apply the skin to your Minecraft character.

## Use

1. Launch Minecraft.
2. Open the Dressing Room or Skin settings, depending on your Minecraft edition.
3. Select the option to import a custom skin.
4. Choose the converted Bloody Thorn Skin PNG file.
5. Select the appropriate player model if prompted.
6. Apply the skin and use it in-game.
